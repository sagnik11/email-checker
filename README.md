# wq-email-checker (Node.js)

This repository now contains the Node.js migration of the email checker backend.

## Project location

- Main app: `nodejs/`

## Quick start

```bash
cd nodejs
npm install
npm test
npm run start
```

## CLI

```bash
cd nodejs
npm install -g .
wq-email-checker --help
```
